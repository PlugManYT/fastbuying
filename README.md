**FastBuying** — это инновационный плагин для автоматизации доната на серверах Minecraft, который радикально упрощает процесс покупки привилегий для игроков.

Плагин полностью автономен, не требует сторонних зависимостей и легко интегрируется с DeluxeMenus, LuckPerms, EssentialsX, CMI, LiteBans и другими плагинами.

## ✨Ключевые особенности
Покупка прямо из игры — интерактивные кнопки в чате

Два типа оплаты: self — свой магазин YooMoney external — через магазин YooMoney от FastBuying

Умная система доплаты — покупай лучшую привилегию, доплачивая разницу

Покупка валюты — игрок сам вводит количество

Полная кастомизация — настрой все сообщения в messages.yml

Интеграция с DeluxeMenus — красивые меню донатов

Поддержка популярных ядер — Spigot, Paper, Purpur и их форки

Мгновенная проверка оплаты — без задержек и очередей

Безопасность — ключи сохраняются только у вас на сервере и не передаются сторонним лицам

Гибкая система цен — фиксированная стоимость товаров, изменяемая вами

Активная поддержка — плагин активно поддерживается автором.


## 📊Статистика

⚡ В 10 раз быстрее традиционного автодоната

🎯 На 85% больше конверсий — игроки чаще завершают покупку

💭До 40% меньше обращений в поддержку — процесс покупки максимально понятен

🧩0 конфликтов с другими плагинами — полностью изолированная логика

🚀 Поддержка Minecraft 1.16.5 - 1.21+


## Команды

/fb <игрок> <товар> - Создать платёж

/fb check - Проверить платёж

/fb update - Проверить обновления

/fb reload - Перезагрузить конфиг

## Права

fastbuying.admin - Доступ к команде перезагрузки конфигурации
